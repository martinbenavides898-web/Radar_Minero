# Radar Minero — Versión 0.2

Primera integración con fuentes reales.

## Cambios principales

- Las tarjetas abren el artículo exacto, no la portada del medio.
- La imagen se obtiene desde la publicación original o el feed RSS.
- Se eliminan las fotografías aleatorias de banco de imágenes.
- Si un artículo no tiene imagen, se muestra una portada neutra de Radar Minero.
- Conector chileno inicial: Codelco.
- Conector internacional inicial: MINING.com.
- Caché de noticias durante tres horas.
- Respaldo controlado si una fuente no responde.
