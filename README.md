
# Radar Minero — Versión 0.8

Refinamiento visual de la aplicación con una dirección de arte más orgánica,
minimalista y luminosa.

## Concepto

La interfaz abandona el look demasiado oscuro y pasa a un lenguaje visual inspirado
en mineralogía chilena:

- base clara, cálida y limpia;
- acentos en cobre;
- verde atacamita como color identitario secundario;
- tarjetas más aireadas;
- menor peso visual y mejor lectura móvil.

## Cambios de diseño

- Nuevo fondo suave con profundidad ligera.
- Cards blancas/mineral con sombras más delicadas.
- Cinta de mercados más liviana y transparente.
- "Radar Minero" con acento visual en **Minero**.
- Pills de categoría y enlaces con identidad atacamita/cobre.
- Estados skeleton adaptados a la nueva paleta.

## Filosofía

No se agregaron funciones nuevas. Esta versión busca solamente elevar la percepción
visual del producto sin caer en una interfaz recargada.
